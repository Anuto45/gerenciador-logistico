Gerenciador Logístico — Protótipo das telas (Etapa 1 – Análise)

APO · Fundamentos de Programação para Internet · UNIPAR EAD · Framework visual: Bootstrap 5

Problema: controlar o transporte de mercadorias cadastrando produtos, endereços (origem/destino) e transportadores, e gerando fretes que relacionam esses dados — um transportador pode levar vários produtos (1 para N) — com relatório diário para download.

Mapa de navegação (menu superior fixo em todas as telas):

Boas práticas de UX adotadas: navegação consistente e sempre visível; rótulos claros e campos obrigatórios marcados com *; feedback após cada ação (mensagens de sucesso/erro); confirmação antes de excluir; máscaras de CEP, CNPJ e telefone; totais calculados em tempo real no frete; layout responsivo; poucos elementos por tela (hierarquia visual simples).

Modelo de dados: produtos · enderecos · transportadores · fretes (transportador, origem, destino, data) · frete_produtos (frete, produto, quantidade) — relação 1:N entre frete e produtos.
